# Homebrew Tap for proc

[![Homebrew](https://img.shields.io/badge/Homebrew-tap-FBB040?logo=homebrew&logoColor=white)](https://brew.sh)
[![Version](https://img.shields.io/crates/v/proc-cli?label=version)](https://github.com/yazeed/proc-cli/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Homebrew tap for [proc](https://github.com/yazeed/proc-cli): semantic CLI tool for process management. Target by port, PID, name or path.

## Install

```bash
brew install yazeed/proc/proc
```

This adds the tap for you, so no separate `brew tap` is needed. The formula installs the prebuilt release binary for macOS or Linux (Apple Silicon, Intel, ARM64 and x86_64).

## Update

```bash
brew update && brew upgrade proc
```
